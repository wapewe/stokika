## GENERAL QUESTIONS

### What is Stokika?
Stokika is a B2B supply chain management platform that connects vendors (shop owners) with suppliers, managed by field agents and supervisors. It streamlines ordering, payment, and delivery processes.

### Who can use Stokika?
- **Vendors**: Business owners who need to order products
- **Suppliers**: Product providers who fulfill orders
- **Field Agents**: Sales representatives who assist vendors
- **Supervisors**: Regional managers who oversee field agents
- **Admins**: Platform administrators

### Is Stokika free to use?
- **Vendors & Suppliers**: Free to register and use
- **Field Agents**: KES 2,500 one-time kit fee
- **Supervisors**: KES 5,000 one-time kit fee

### What browsers are supported?
Stokika works best on:
- Google Chrome (recommended)
- Mozilla Firefox
- Safari
- Microsoft Edge

### Is my data secure?
Yes! We use:
- SSL encryption for all data
- Secure authentication
- Row-level security in database
- Regular security audits
- Data backup systems

### Can I use Stokika on mobile?
Yes! The platform is mobile-responsive. Field agents can also work offline and sync later.

## ACCOUNT & LOGIN

### How do I create an account?

**Vendors & Suppliers**:
1. Contact a field agent or
2. Register through the website (if enabled)

**Field Agents & Supervisors**:
1. Fill out application form
2. Pay kit fee
3. Wait for admin approval
4. Receive login credentials via email

### I forgot my password. What do I do?
1. Go to login page
2. Click "Forgot Password?"
3. Enter your email
4. Check email for reset link
5. Click link and create new password

### I'm not receiving the password reset email
Check:
- Spam/junk folder
- Email address spelling
- Email filters
- Wait 10 minutes and try again
- Contact support if still not received

### Can I change my email address?
Yes:
1. Login to your dashboard
2. Go to Settings
3. Update email address
4. Verify new email
5. Save changes

### How do I change my password?
1. Login to dashboard
2. Go to Settings → Security
3. Enter current password
4. Enter new password
5. Confirm new password
6. Save changes

### My account is locked. What happened?
Accounts lock after:
- 5 failed login attempts
- Suspicious activity detected
- Admin deactivation

**Solution**: Contact admin or support to unlock.

### Can I have multiple accounts?
No. Each user should have only one account. Multiple accounts may be flagged and suspended.

## VENDOR QUESTIONS

### How do I place an order?
1. Login to vendor dashboard
2. Click "Orders" → "Create New Order"
3. Select supplier
4. Enter product details
5. Enter quantity and amount
6. Submit order

### How long does order approval take?
- Admin assignment: 2-4 hours
- Supplier acceptance: 24 hours
- Total: Usually within 24-48 hours

### Can I cancel an order?
Yes, if order status is:
- ✅ Pending Admin
- ✅ Pending Supplier
- ❌ Accepted (contact supplier)
- ❌ Processing (contact supplier)
- ❌ Delivered (cannot cancel)

### How do I track my order?
1. Go to Orders tab
2. Find your order
3. Check status:
   - Pending Admin: Being assigned
   - Pending Supplier: Awaiting acceptance
   - Accepted: Supplier confirmed
   - Processing: Being prepared
   - Delivered: Completed

### What payment methods are accepted?
- M-Pesa (manual entry)
- M-Pesa (auto STK push)
- Bank transfer (contact admin)

### How do I submit payment proof?
1. Go to Payments tab
2. Click "Submit Payment"
3. Choose payment method
4. Enter M-Pesa code and phone number
5. Submit

### My payment was rejected. Why?
Common reasons:
- Invalid M-Pesa code
- Wrong amount
- Duplicate payment
- Expired transaction
- Mismatched phone number

**Solution**: Check rejection reason and resubmit with correct information.

### Can I order from multiple suppliers?
Yes! Create separate orders for each supplier.

### Do you offer credit?
Credit terms depend on:
- Your payment history
- Order frequency
- Business relationship
- Admin approval

Contact your field agent to discuss credit options.

### How do I rate a supplier?
After order delivery:
1. Go to completed order
2. Click "Rate Supplier"
3. Give 1-5 stars
4. Leave review (optional)
5. Submit

## SUPPLIER QUESTIONS

### How do I receive orders?
Orders are assigned by admin based on:
- Product availability
- Location proximity
- Supplier rating
- Delivery capacity

You'll receive email/SMS notification.

### Can I decline an order?
Yes:
1. View order details
2. Click "Decline"
3. Select reason
4. Add notes
5. Confirm

### What happens if I decline too many orders?
- Rating decreases
- Fewer orders assigned
- Possible account review
- May lose supplier status

### How do I update my product inventory?
1. Go to Inventory tab
2. Find product
3. Click "Edit"
4. Update stock quantity
5. Save changes

### Can I add new products?
Yes:
1. Go to Inventory
2. Click "Add Product"
3. Enter product details
4. Set price and stock
5. Save

### How do I update order status?
1. Find order in Orders tab
2. Click order to open
3. Click status button:
   - "Mark as Processing"
   - "Mark as Delivered"
4. Upload proof (optional)
5. Confirm

### When do I get paid?
Payment terms:
- Vendor pays before/on delivery
- Payment verified by admin
- Funds released to supplier
- Typical timeline: 3-5 business days

### Can I set my own prices?
Yes! You control your product prices. Update anytime in Inventory section.

### How do I handle delivery?
Options:
- Self-delivery
- Third-party courier
- Vendor pickup

Coordinate with vendor and update order status accordingly.

### What if a vendor doesn't pay?
1. Don't deliver until payment confirmed
2. Check payment status in system
3. Contact admin if issues
4. Report non-payment

## FIELD AGENT QUESTIONS

### How do I apply to become a field agent?
1. Go to field agent application page
2. Complete all 9 sections
3. Upload required documents
4. Pay KES 2,500 kit fee
5. Submit application
6. Wait for admin review (48 hours)

### What's included in the starter kit?
- Branded uniform (shirt/jacket)
- Official ID badge
- Training materials
- Mobile app access
- Product catalog
- Sales tools

### How long does approval take?
- Application review: 48 hours
- Background check: 3-5 days
- Training schedule: 1 week
- Total: 1-2 weeks

### Can I create vendors and suppliers?
Only if admin grants you permission:
1. Admin reviews your performance
2. Admin grants "create users" permission
3. You can then create vendor/supplier accounts

### Can I approve orders I create?
No. Field agents CANNOT approve orders. Orders go to:
- Admin for approval, OR
- Supervisor (if activated and has permission)

### How do I log vendor visits?
1. Go to Visits tab
2. Click "Log Visit"
3. Select vendor
4. Add visit notes
5. Upload photos
6. Save visit

### Can I work offline?
Yes! The dashboard saves data locally:
- Create orders offline
- Log visits offline
- Data syncs when online
- Check sync status in top-right

### How is my performance measured?
Metrics include:
- Number of vendors managed
- Orders created
- Visit frequency
- Order accuracy
- Vendor satisfaction
- Response time

### How do I get promoted to supervisor?
Requirements:
- Minimum 6 months as field agent
- Good performance record
- Leadership qualities
- Admin recommendation
- Complete supervisor training

### What's my commission structure?
Commission details:
- Based on orders created
- Paid monthly
- View in Performance tab
- Contact admin for specific rates

## SUPERVISOR QUESTIONS

### How do I become a supervisor?
1. Apply through supervisor application form
2. Pay KES 5,000 kit fee
3. Wait for admin approval
4. Complete management training
5. Wait for admin activation
6. Receive order approval permission

### What's the difference between activation and approval permission?

**Activation**:
- Access to supervisor dashboard
- View assigned agents
- View territory data
- Generate reports

**Approval Permission** (separate):
- Approve/reject orders
- Manage order workflow
- Full supervisor authority

### Why can't I approve orders yet?
You need BOTH:
1. ✅ Account activated by admin
2. ✅ Approval permission granted by admin

Check with admin if you're missing either.

### How many field agents can I manage?
Depends on:
- Territory size
- Your experience
- Admin assignment
- Typical: 5-15 agents

### Can I create orders?
No. Supervisors:
- ✅ Approve orders
- ✅ Manage agents
- ✅ Monitor territory
- ❌ Create orders (agents do this)

### How do I approve an order?
1. Go to Orders tab
2. Find orders with "Pending Approval"
3. Review order details
4. Click "Approve" or "Reject"
5. If rejecting, enter reason
6. Confirm action

### What if I approve a wrong order?
Contact admin immediately:
- Explain the situation
- Admin can reverse approval
- Order can be reassigned
- Learn from mistake

### How do I monitor agent performance?
1. Go to Agents tab
2. View agent list
3. Click on agent for details:
   - Orders created
   - Visit logs
   - Performance metrics
   - Vendor feedback

### Can I be demoted?
Yes, if:
- Performance issues
- Policy violations
- Voluntary request
- Territory restructuring

### How do I communicate with my team?
- In-app messaging (if enabled)
- Email through platform
- Phone/SMS
- Team meetings
- Group chats

## PAYMENT QUESTIONS

### What payment methods do you accept?
- **M-Pesa**: Primary method
- **Bank Transfer**: For large amounts
- **Cash**: Through field agents (limited)

### How do I pay via M-Pesa?

**Manual Payment**:
1. Pay via M-Pesa first
2. Submit payment in dashboard
3. Enter M-Pesa code
4. Wait for verification

**Auto Payment**:
1. Click "Auto Payment"
2. Enter phone number
3. Approve STK push
4. Payment auto-verified

### How long does payment verification take?
- **Auto Payment**: Instant
- **Manual Payment**: Up to 24 hours
- **Bank Transfer**: 2-3 business days

### My payment is still pending. Why?
Reasons:
- Admin hasn't verified yet (wait 24 hours)
- Weekend/holiday (wait for business day)
- Invalid M-Pesa code (check and resubmit)
- System delay (contact support)

### Can I get a refund?
Refunds available for:
- ✅ Cancelled orders (before processing)
- ✅ Duplicate payments
- ✅ Overpayments
- ❌ Completed orders
- ❌ Change of mind

Contact admin to request refund.

### Is there a payment limit?
Limits:
- Minimum order: KES 500
- Maximum order: KES 500,000
- Daily limit: KES 1,000,000
- Contact admin for higher limits

### Do you charge transaction fees?
- **Vendors**: No platform fees
- **Suppliers**: Small commission on sales
- **M-Pesa**: Standard M-Pesa charges apply

### Can I pay in installments?
Depends on:
- Your credit history
- Order amount
- Supplier agreement
- Admin approval

Contact your field agent to discuss.

### What if I entered wrong M-Pesa code?
1. Payment will be rejected
2. Check rejection reason
3. Find correct M-Pesa code in SMS
4. Resubmit with correct code

### How do I download payment receipts?
1. Go to Payments tab
2. Find approved payment
3. Click "Download Receipt"
4. Save PDF file

## TECHNICAL ISSUES

### The website won't load
Try:
1. Check internet connection
2. Refresh page (Ctrl + F5)
3. Clear browser cache
4. Try different browser
5. Try incognito/private mode
6. Contact support

### I can't login
Check:
- Email spelling
- Password (case-sensitive)
- Caps Lock is off
- Account is active
- Using correct user type

Try "Forgot Password" if needed.

### The page is loading slowly
Reasons:
- Slow internet connection
- Server maintenance
- Too many users online
- Large data loading

**Solutions**:
- Wait a moment
- Refresh page
- Try later
- Contact support if persistent

### I can't upload files
Check:
- File size (max 5MB)
- File format (PDF, JPG, PNG)
- Internet connection
- Browser permissions

**Solutions**:
- Reduce file size
- Convert to supported format
- Try different file
- Try different browser

### Forms won't submit
Check:
- All required fields filled (red asterisk)
- Valid email format
- Valid phone format
- Internet connection
- No special characters in text

### I'm not receiving notifications
Check:
- Email address is correct
- Check spam/junk folder
- Notification settings enabled
- Email filters
- Contact admin to resend

### The dashboard looks broken
Try:
- Refresh page
- Clear browser cache
- Update browser
- Disable browser extensions
- Try different browser

### GPS tracking isn't working
Check:
- Location permissions enabled
- GPS enabled on device
- Internet connection
- Browser supports geolocation
- Try different browser

### Offline mode not syncing
Check:
- Internet connection restored
- Browser storage not full
- Sync icon in top-right
- Refresh page
- Clear browser cache

### I see an error message
1. Take screenshot of error
2. Note what you were doing
3. Try refreshing page
4. Contact support with:
   - Error message
   - Screenshot
   - What you were doing
   - Your user type
