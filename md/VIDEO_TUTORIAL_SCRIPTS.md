## VENDOR TUTORIALS

### Video 1: Getting Started as a Vendor (5 minutes)

**INTRO (30 seconds)**
```
[Screen: Stokika homepage]

"Welcome to Stokika! I'm going to show you how to get started as a vendor 
on our platform. By the end of this video, you'll know how to login, 
navigate your dashboard, and place your first order."
```

**SECTION 1: First Login (1 minute)**
```
[Screen: Login page]

"First, go to the Stokika website and click 'Launch Dashboard'.

[Click button]

Select 'Vendor' from the dropdown menu.

[Select Vendor]

Enter your email address and password that you received in your welcome email.

[Type credentials]

Click 'Sign In'.

[Click button]

Great! You're now in your vendor dashboard."
```

**SECTION 2: Dashboard Overview (1.5 minutes)**
```
[Screen: Vendor dashboard]

"Let's look at your dashboard. At the top, you can see four key metrics:

[Point to each]

1. Total Orders - all orders you've placed
2. Pending Orders - orders being processed
3. Total Payments - amount you've paid
4. Active Suppliers - suppliers you work with

On the left sidebar, you have:
- Dashboard - overview page
- Orders - manage your orders
- Payments - submit and track payments
- Suppliers - view your suppliers
- Settings - update your profile

Let's place your first order."
```

**SECTION 3: Placing an Order (2 minutes)**
```
[Screen: Orders page]

"Click 'Orders' in the sidebar.

[Click Orders]

Now click 'Create New Order'.

[Click button]

Fill in the order details:

[Fill form while explaining]

1. Select your supplier from the dropdown
2. Enter the product name - for example, 'Rice 50kg bags'
3. Enter the quantity - let's say 10 bags
4. Enter the total amount - 50,000 shillings

Review your order details, then click 'Submit Order'.

[Click Submit]

Perfect! Your order has been submitted. The admin will assign a supplier, 
and you'll receive a notification when your order is accepted."
```

**OUTRO (30 seconds)**
```
[Screen: Dashboard]

"That's it! You've successfully placed your first order. In the next video, 
we'll show you how to submit payments. If you have any questions, contact 
your field agent or our support team. Thank you for using Stokika!"
```

### Video 2: Submitting Payments (4 minutes)

**INTRO (20 seconds)**
```
"In this video, I'll show you how to submit payments on Stokika. 
We have two payment methods: Manual Payment if you've already paid, 
and Auto Payment to pay directly through the platform."
```

**SECTION 1: Manual Payment (2 minutes)**
```
[Screen: Payments page]

"Click 'Payments' in the sidebar.

[Click Payments]

Click 'Submit Payment'.

[Click button]

Select 'Manual Payment'. Use this if you've already paid via M-Pesa.

[Click Manual Payment]

Now enter your payment details:

[Fill form]

1. M-Pesa Transaction Code - this is the code you received via SMS
   For example: QGH7KLM9XY

2. Phone Number - the number you used to pay
   Format: 0712345678

3. Payment Reference - optional, you can add your order number

Click 'Submit'.

[Click Submit]

Your payment has been submitted! The admin will verify it within 24 hours, 
and you'll receive an email confirmation."
```

**SECTION 2: Auto Payment (1.5 minutes)**
```
[Screen: Payment method selection]

"Now let's try Auto Payment. This sends an STK push to your phone.

[Click Auto Payment]

Enter your M-Pesa phone number.

[Type number]

Click 'Submit'.

[Click Submit]

Now check your phone. You should see an M-Pesa prompt.

[Show phone screen]

Enter your M-Pesa PIN to complete the payment.

[Enter PIN]

Done! Your payment is automatically verified."
```

**OUTRO (20 seconds)**
```
"That's how easy it is to submit payments on Stokika. Remember, 
manual payments take up to 24 hours to verify, while auto payments 
are instant. Choose the method that works best for you!"
```

## SUPPLIER TUTORIALS

### Video 3: Managing Orders as a Supplier (6 minutes)

**INTRO (30 seconds)**
```
[Screen: Supplier dashboard]

"Welcome, suppliers! In this video, you'll learn how to manage orders 
on Stokika. We'll cover accepting orders, declining orders, and updating 
order status through delivery."
```

**SECTION 1: Accepting Orders (2 minutes)**
```
[Screen: Orders page]

"When a vendor places an order, you'll receive a notification.

Click 'Orders' in the sidebar.

[Click Orders]

You'll see orders with status 'Pending Supplier'. These need your action.

[Point to pending orders]

Click on an order to view details.

[Click order]

Review the order information:
- Vendor name and location
- Product requested
- Quantity
- Total amount
- Delivery location

If you can fulfill this order, click 'Accept Order'.

[Click Accept]

The order status changes to 'Accepted', and the vendor is notified."
```

**SECTION 2: Declining Orders (1.5 minutes)**
```
[Screen: Order details]

"If you can't fulfill an order, click 'Decline'.

[Click Decline]

You must provide a reason. Select from:
- Product out of stock
- Cannot deliver to location
- Price changed
- Other

[Select reason]

Add additional notes if needed, then click 'Confirm Decline'.

[Click Confirm]

The order is declined, and the admin will assign another supplier."
```

**SECTION 3: Processing and Delivery (2 minutes)**
```
[Screen: Accepted orders]

"After accepting an order, click 'Mark as Processing' when you start 
preparing it.

[Click Processing]

The vendor can now track that you're working on their order.

When the order is ready and delivered, click 'Mark as Delivered'.

[Click Delivered]

You can upload delivery proof - a photo or document.

[Upload file]

Click 'Confirm Delivery'.

[Click Confirm]

Perfect! The order is complete, and payment will be processed."
```

**OUTRO (30 seconds)**
```
"That's how you manage orders on Stokika. Remember: accept orders promptly, 
communicate any delays, and always update the order status. This keeps 
vendors happy and builds your reputation!"
```

### Video 5: Creating Orders for Vendors (5 minutes)

**INTRO (20 seconds)**
```
"As a field agent, one of your main tasks is creating orders for your 
vendors. Let me show you how to do this correctly."
```

**SECTION 1: Accessing Order Creation (1 minute)**
```
[Screen: Agent dashboard]

"Login to your field agent dashboard.

[Login]

Click 'Orders' in the sidebar.

[Click Orders]

Click 'Create Order'.

[Click button]

You'll see the order creation form."
```

**SECTION 2: Filling Order Details (2.5 minutes)**
```
[Screen: Order form]

"Fill in the order details carefully:

[Fill form]

1. Select Vendor - choose from your assigned vendors
   If you don't see a vendor, you may need permission to create them

2. Select Supplier - choose the appropriate supplier
   Consider location and product availability

3. Product Name - be specific
   Example: 'Maize Flour 2kg packets' not just 'flour'

4. Quantity - enter the amount
   Example: 50 packets

5. Total Amount - calculate correctly
   Example: 50 packets × 150 = 7,500 shillings

6. Add notes if needed - delivery instructions, special requests

Review all details carefully. Mistakes can cause delays.

Click 'Submit Order'.

[Click Submit]"
```

**SECTION 3: Important Notes (1 minute)**
```
[Screen: Success message]

"Important: You CANNOT approve orders. Your orders go to the admin or 
supervisor for approval.

[Show message]

You'll see this message: 'Order created successfully. This order will 
be reviewed by Admin or Supervisor for approval.'

Track your order status in the Orders tab. You'll be notified when 
it's approved."
```

**OUTRO (30 seconds)**
```
"That's how to create orders for vendors. Always double-check details, 
communicate with vendors, and follow up on order status. Quality work 
leads to better performance ratings!"
```

## PRODUCTION NOTES

### Video Recording Tips

**Equipment Needed**:
- Screen recording software (OBS Studio, Camtasia, or ScreenFlow)
- Good microphone
- Quiet recording environment
- Test account with sample data

**Recording Settings**:
- Resolution: 1920x1080 (1080p)
- Frame rate: 30fps
- Audio: 44.1kHz, stereo
- Format: MP4 (H.264)

**Best Practices**:
- Record in short segments
- Use cursor highlighting
- Speak clearly and slowly
- Pause between sections
- Show real examples
- Include captions

### Editing Checklist

- [ ] Remove long pauses
- [ ] Add intro/outro graphics
- [ ] Include background music (low volume)
- [ ] Add text overlays for key points
- [ ] Highlight cursor clicks
- [ ] Add zoom effects for important details
- [ ] Include chapter markers
- [ ] Add captions/subtitles
- [ ] Export in multiple resolutions (1080p, 720p, 480p)

### Publishing Checklist

- [ ] Upload to video platform (YouTube, Vimeo)
- [ ] Create playlist for each user type
- [ ] Add video descriptions
- [ ] Include timestamps in description
- [ ] Add relevant tags
- [ ] Create thumbnail images
- [ ] Link to documentation
- [ ] Embed in dashboard help section
- [ ] Share with users via email
- [ ] Track view analytics
