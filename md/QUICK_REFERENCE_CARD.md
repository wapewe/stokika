## 🔐 LOGIN

**URL**: `https://yourdomain.com`

1. Click **"Launch Dashboard"**
2. Select your role
3. Enter email + password
4. Click **"Sign In"**

**Forgot Password?** → Click link → Enter email → Check inbox

## 👥 USER ROLES

| Role | Main Function | Can Approve Orders? |
|------|---------------|---------------------|
| **Vendor** | Order products | ❌ |
| **Supplier** | Fulfill orders | Own orders only |
| **Field Agent** | Create orders | ❌ |
| **Supervisor** | Manage agents | ✅ (if activated) |
| **Admin** | Manage platform | ✅ |

---

## 📦 ORDER WORKFLOW

```
Create Order → Pending Admin → Pending Supplier → 
Accepted → Processing → Delivered
```

**Vendors**: Create orders  
**Field Agents**: Create orders for vendors  
**Admin**: Assign suppliers  
**Supervisors**: Approve orders (if activated)  
**Suppliers**: Accept/process/deliver

---

## 💰 PAYMENT METHODS

### Manual Payment (Already Paid)
1. Pay via M-Pesa first
2. Submit payment in dashboard
3. Enter M-Pesa code
4. Enter phone number
5. Wait for admin approval

### Auto Payment (Pay Now)
1. Click "Auto Payment"
2. Enter phone number
3. Approve STK push on phone
4. Enter M-Pesa PIN
5. Payment auto-verified

## 🎯 COMMON ACTIONS

### Place Order (Vendor/Agent)
`Orders → Create New → Fill details → Submit`

### Submit Payment (Vendor)
`Payments → Submit Payment → Choose method → Submit`

### Accept Order (Supplier)
`Orders → Find order → Accept/Decline`

### Approve Order (Supervisor/Admin)
`Orders → Find order → Approve/Reject`

### Create User (Admin)
`Users → Create User → Fill form → Create`

### Activate Supervisor (Admin)
`Supervisors → Find supervisor → Activate`

## 📊 ORDER STATUS MEANINGS

| Status | What It Means | Who Acts Next |
|--------|---------------|---------------|
| **Pending Admin** | Needs supplier assignment | Admin |
| **Pending Supplier** | Waiting for supplier | Supplier |
| **Accepted** | Supplier accepted | Supplier |
| **Processing** | Being prepared | Supplier |
| **Delivered** | Completed | None |
| **Declined** | Rejected | Check reason |

## 🚨 TROUBLESHOOTING

### Cannot Login
- Check email spelling
- Verify password
- Try "Forgot Password"
- Clear browser cache

### Payment Not Showing
- Refresh page
- Wait 5-10 minutes
- Check M-Pesa code
- Contact admin

### Order Stuck
- Refresh page
- Check status
- Contact supplier/admin
- Wait for processing

### Upload Failed
- Check file size (max 5MB)
- Use PDF/JPG/PNG only
- Check internet
- Try again
