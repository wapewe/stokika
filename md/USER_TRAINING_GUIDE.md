## GETTING STARTED

### System Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (Field agents can work offline)
- Valid email address
- Mobile phone number (for M-Pesa payments)

### First Time Login
1. Open your browser and go to: `https://yourdomain.com`
2. Click **"Launch Dashboard"** button
3. Select your user type from dropdown
4. Enter your email and password
5. Click **"Sign In"**

### Password Requirements
- Minimum 8 characters
- At least one uppercase letter
- At least one number
- At least one special character

### Forgot Password?
1. Click **"Forgot Password?"** on login page
2. Enter your email address
3. Check your email for reset link
4. Click link and create new password

## VENDOR GUIDE

### Dashboard Overview
Your dashboard shows:
- **Total Orders**: All orders you've placed
- **Pending Orders**: Orders awaiting processing
- **Total Payments**: Amount you've paid
- **Active Suppliers**: Suppliers you work with

### How to Place an Order

#### Step 1: Navigate to Orders
1. Click **"Orders"** in sidebar
2. Click **"Create New Order"** button

#### Step 2: Fill Order Details
1. **Select Supplier**: Choose from dropdown
2. **Product Name**: Enter product you need
3. **Quantity**: Enter amount needed
4. **Total Amount**: Enter total cost
5. Click **"Submit Order"**

#### Step 3: Track Order Status
- **Pending Admin**: Admin is assigning supplier
- **Pending Supplier**: Waiting for supplier acceptance
- **Accepted**: Supplier accepted your order
- **Processing**: Supplier is preparing order
- **Delivered**: Order completed

### How to Make Payment

#### Option 1: Manual Payment (Already Paid)
1. Go to **"Payments"** tab
2. Click **"Submit Payment"**
3. Select **"Manual Payment"**
4. Enter M-Pesa transaction code
5. Enter phone number used
6. Add reference (optional)
7. Click **"Submit"**

#### Option 2: Auto Payment (Pay Now)
1. Go to **"Payments"** tab
2. Click **"Submit Payment"**
3. Select **"Auto Payment"**
4. Enter your M-Pesa phone number
5. Wait for STK push on your phone
6. Enter M-Pesa PIN to complete

### Managing Your Profile
1. Click **"Settings"** in sidebar
2. Update your information:
   - Business name
   - Contact details
   - Location
   - Notification preferences
3. Click **"Save Changes"**

### Viewing Payment History
1. Go to **"Payments"** tab
2. View all payments with status:
   - **Pending**: Awaiting verification
   - **Approved**: Payment confirmed
   - **Rejected**: Payment declined (check reason)

### Tips for Vendors
- ✅ Keep your contact information updated
- ✅ Submit payment proof immediately after paying
- ✅ Track your orders regularly
- ✅ Maintain good relationship with suppliers
- ✅ Report any issues to your field agent

## FIELD AGENT GUIDE

### Dashboard Overview
Your dashboard shows:
- **Total Vendors**: Vendors you manage
- **Total Orders**: Orders you've created
- **Pending Orders**: Orders awaiting approval
- **Performance Score**: Your rating

### Applying to Become Field Agent

#### Step 1: Access Application Form
1. Go to: `https://yourdomain.com/html/field-agent.html`
2. Click **"Start Application"**

#### Step 2: Complete All Sections
1. **Personal Information**
   - Full name, email, phone
   - ID number, date of birth
   - County and location

2. **Contact Information**
   - Physical address
   - Emergency contact

3. **Education Background**
   - Highest level completed
   - Institution name
   - Year completed

4. **Work Experience**
   - Previous employer
   - Position held
   - Duration

5. **Skills & Qualifications**
   - Relevant skills
   - Languages spoken
   - Computer literacy

6. **References**
   - Two professional references
   - Contact information

7. **Availability**
   - Start date
   - Working hours preference

8. **Documents Upload**
   - ID copy
   - CV/Resume
   - Certificates

9. **Declaration**
   - Read terms
   - Accept declaration
   - Submit application

#### Step 3: Kit Payment
1. After submission, you'll receive payment link
2. Pay KES 2,500 for starter kit
3. Kit includes:
   - Branded uniform
   - ID badge
   - Training materials
   - Mobile app access

### Creating Vendors (After Approval)
1. Click **"Vendors"** tab
2. Click **"Add Vendor"** (if you have permission)
3. Fill vendor details:
   - Business name
   - Owner name
   - Contact information
   - Location
4. Click **"Submit"**

### Creating Orders for Vendors
1. Go to **"Orders"** tab
2. Click **"Create Order"**
3. Select vendor
4. Select supplier
5. Enter product details
6. Enter quantity and amount
7. Click **"Submit Order"**

**IMPORTANT**: You CANNOT approve orders. Orders go to Admin/Supervisor for approval.

### Logging Vendor Visits
1. Click **"Visits"** tab
2. Click **"Log Visit"**
3. Select vendor
4. Add visit notes
5. Upload photos (optional)
6. Click **"Save Visit"**

### Working Offline
1. Dashboard automatically saves data locally
2. Continue working without internet
3. Data syncs automatically when online
4. Check sync status in top-right corner

### Tips for Field Agents
- ✅ Visit vendors regularly
- ✅ Log all visits with photos
- ✅ Create accurate orders
- ✅ Maintain good vendor relationships
- ✅ Report issues to supervisor
- ✅ Keep your phone charged for GPS tracking

## TROUBLESHOOTING

### Cannot Login
**Problem**: Login fails with error message

**Solutions**:
1. Check email spelling
2. Verify password is correct
3. Try "Forgot Password" link
4. Clear browser cache
5. Try different browser
6. Contact admin if issue persists

### Payment Not Showing
**Problem**: Submitted payment not visible

**Solutions**:
1. Refresh the page
2. Check payment status (may be pending)
3. Verify M-Pesa code is correct
4. Wait 5-10 minutes for processing
5. Contact admin with M-Pesa code

### Order Status Not Updating
**Problem**: Order stuck in same status

**Solutions**:
1. Refresh the page
2. Check internet connection
3. Contact supplier/admin
4. Wait for processing (may take time)

### Cannot Upload Documents
**Problem**: File upload fails

**Solutions**:
1. Check file size (max 5MB)
2. Use supported formats (PDF, JPG, PNG)
3. Check internet connection
4. Try different file
5. Contact support

### Offline Mode Not Working
**Problem**: Field agent cannot work offline

**Solutions**:
1. Enable browser storage permissions
2. Clear browser cache
3. Reload page while online
4. Check browser compatibility
5. Update browser to latest version

### GPS Tracking Not Working
**Problem**: Location not being tracked

**Solutions**:
1. Enable location permissions in browser
2. Enable GPS on device
3. Check internet connection
4. Reload the page
5. Try different browser

### Email Not Received
**Problem**: Not receiving system emails

**Solutions**:
1. Check spam/junk folder
2. Verify email address is correct
3. Add system email to contacts
4. Check email filters
5. Contact admin to resend

### Dashboard Not Loading
**Problem**: Dashboard shows blank page

**Solutions**:
1. Check internet connection
2. Clear browser cache and cookies
3. Disable browser extensions
4. Try incognito/private mode
5. Try different browser
6. Contact support

### Permission Denied Error
**Problem**: Cannot access certain features

**Solutions**:
1. Verify your user role
2. Check if admin granted permission
3. Logout and login again
4. Contact admin to grant access

### Payment Rejected
**Problem**: Payment was rejected by admin

**Solutions**:
1. Check rejection reason
2. Verify M-Pesa code is correct
3. Ensure payment amount matches
4. Resubmit with correct information
5. Contact admin for clarification
