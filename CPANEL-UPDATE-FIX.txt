┌─────────────────────────────────────────────────────────────────────┐
│ WHY THIS WORKS                                                       │
└─────────────────────────────────────────────────────────────────────┘

📋 Apache requires an "index" file to serve directory requests

❌ Before: No index.html → 403 Forbidden
✅ After:  index.html exists → Serves page → Redirects to dalana

🔧 .htaccess DirectoryIndex tells Apache which files to look for:
   DirectoryIndex index.html dalana.html

   This means:
   1. Try index.html first
   2. If not found, try dalana.html
   3. If neither found, show 403
