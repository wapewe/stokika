❌ Troubleshooting

If you see: "❌ ERROR: No hero slides found!"

Problem: HTML structure issue. Check that hero-slide elements exist.

If animations don't play:

  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Hard refresh (Ctrl+F5)
  3. Check if fadeInUp animation exists in styles.css
  4. Verify .hero-full-content > * has opacity: 0

If content is invisible:

Check console for errors. The "loaded" class should be added within 1 second of page load.
